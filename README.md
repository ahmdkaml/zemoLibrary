# ZemoLibrary

ZemoLibrary is an open-source online library platform built with **Angular** and **Spring Boot**.

🚧 **This project is currently under active development.**

## Temporary Demo

A temporary preview of the frontend is available at:

👉 https://ahmdkaml.github.io/zemoLibrary/

## Tech Stack

* Angular
* Spring Boot
* Maven
* GitHub Actions

## Status

The project is in its MVP stage. Features and documentation are being added incrementally.
