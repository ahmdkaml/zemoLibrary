# Zemolibrary (React)

Vite + React + TypeScript. Converted from Angular scaffold.

## Run

```bash
npm install
npm run dev
```

## Structure

- `src/components` — Header, Footer, Layout, BookCard, LoadingSpinner, Navbar, Sidebar, RatingStars, Pagination
- `src/pages` — Home, Catalog, BookDetail, Search, Login, Profile, NotFound
- `src/services` — bookService (mock data), authService, searchService, cartService
- `src/models` — Book, User
- `src/App.tsx` — routes
